# CRAWLER POLICY (AEO phase 1, 2026-09-17). One rule set, restated per bot.
#
# A robots.txt group is exclusive: a crawler that finds its own User-agent
# group ignores the `*` group entirely. The previous file gave GPTBot,
# ChatGPT-User, Google-Extended, PerplexityBot and ClaudeBot a bare
# `Allow: /`, which quietly lifted every Disallow below for exactly those
# bots. Every named group now carries the identical Disallow list as `*`;
# __tests__/robots-crawler-policy.law.test.mjs pins the parity.
#
# Which bots are named and why (vendor docs as of September 2026):
#   Search-index crawlers decide whether a page can be CITED in an answer:
#     OAI-SearchBot (ChatGPT search), Claude-SearchBot (Claude), PerplexityBot,
#     meta-webindexer (Meta AI), bingbot (Copilot and, through Bing, ChatGPT),
#     Googlebot (AI Overviews and AI Mode), Applebot (Siri, Spotlight).
#   User-triggered fetchers open a page when a person asks; vendors say
#     robots.txt may not apply to them, so they are listed for intent only:
#     ChatGPT-User, Claude-User, Perplexity-User, meta-externalfetcher.
#   Training crawlers are allowed on purpose. Blocking them does not affect
#     citation; allowing them keeps the brand in the models' own knowledge:
#     GPTBot, ClaudeBot, meta-externalagent, Amazonbot, Applebot-Extended,
#     Google-Extended (a token, not a bot; it never affects Search).
#
# Content-Signal is the Cloudflare/IETF robots.txt convention for AI use.
# The site is not behind Cloudflare; the line states the policy machine-readably
# for any crawler that honours it.
#
# /horses IS THE STAFF ADMIN CONSOLE (AEO phase 3, 2026-09-17). An email and
# password form, a roster table and an SQL console, gated on profiles.is_admin.
# It sat in the sitemap at priority 0.7 and returned 11 words and no title to a
# crawler. It left the sitemap; disallowing it here stops a crawler spending
# budget on an admin login. Restated in every group, like the rest of the list.
#
# ACCOUNT-ONLY PATHS (2026-09-17, discoverability phase 1). Messenger,
# notifications, settings, profile edit, the store cart/orders/wishlist, a
# player's own reels and trivia settings all need a session: a crawler lands
# on the login page. They left the sitemap on 2026-09-16; disallowing them
# here stops every crawler spending its budget on login redirects. Restated
# in every group, like the rest of the list.
