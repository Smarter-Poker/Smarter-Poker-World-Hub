# World Hub Command Menu Modernization

Date: 2026-08-31
Scope: Personal Assistant, Training Games, Poker News, Poker Trivia, Social Media, Diamond Arena, My Clubs, Video Library, Odds Calculator, Bankroll Manager, Toke Tracker, Preflop Charts, Poker Near Me, And Marketplace

## Authority And Inventory

The machine-readable route/content inventory is
`.agent/audits/2026-08-31-world-hub-menu-route-inventory.json`. It contains all
203 physical Pages Router routes owned by the 14 worlds, including compatibility
routes `/pokerbrain` and `/u/[username]`. Each entry records its source module,
disposition, pre-change menu coverage, direct menu key, role/context signals,
Supabase tables and RPCs, API routes, realtime and mutation signals, addressable
query states, and explicit loading/empty/error/permission/offline/partial/success
signals found in the route source.

The inventory is generated by `scripts/generate-world-menu-audit.mjs` and is
enforced by `__tests__/world-command-menu-law.test.mjs`.

## Before Sitemap And Findings

Before this change, menu coverage was fragmented:

- 30 routes mounted a page-owned drawer.
- 57 routes mounted a shared header but relied on its generic Hub menu.
- 116 routes had no route-specific command drawer.
- The existing configuration had no dedicated Marketplace, My Clubs, or Odds
  Calculator menu.
- The Social menu existed under an internal alias and was not resolved from the
  active route by the header fallback.
- Several Training menu configurations existed but were never requested by the
  pages they were intended to serve.
- The header's three-bar symbol was embedded in the approved bitmap. Nine more
  obsolete bar-image assets remained under `public/images` despite having no
  code references.
- World footer identity and menu identity could drift because route ownership,
  labels, and primary destinations were maintained independently.

## Disposition Ledger

Every physical route is listed in the inventory. The release applies these
dispositions:

| Disposition | Application |
| --- | --- |
| RETAIN + REDESIGN NAVIGATION | All working primary and nested world routes remain live and receive the new adaptive command surface. |
| RETAIN COMPATIBILITY | `/hub/bankroll`, `/pokerbrain`, `/u/[username]`, and other working compatibility entry points remain available. |
| REDIRECT | Existing server-owned redirect routes, including `/hub/marketplace` and `/hub/poker-near-me`, continue to preserve query strings and canonical ownership. |
| MERGE | Footer primary destinations and menu primary destinations now come from the same world registry. Repeated primary rows are removed from page-specific sections. |
| RENAME | Source titles were normalized to strict Title Case where drift existed. URLs were not renamed. |
| REMOVE | Nine unreferenced World Hub three-bar image assets were removed. No business route, handler, or data contract was removed. |
| ADD | Marketplace, My Clubs, and Odds Calculator command configurations; route-aware fallback; global legacy-route dock; permanent navigation and no-bar laws. |
| EXTERNAL AUTHORITY | Club Arena remains owned by its source application. Compiled output under `public/hub/club-arena` is not edited by this repository. |

## Adaptive Behavior

- Pages with a page-owned menu retain their live actions and settings while
  receiving the canonical world deck.
- Pages with the approved header but no page-owned menu resolve the correct
  world automatically.
- Legacy nested routes without a shared header receive one floating world
  command node. It disappears when an approved header trigger is present, so
  duplicate menus are impossible.
- Destination search includes labels and descriptions.
- User pins and recents remain persisted per world.
- Offline state is advisory; only destinations explicitly requiring the
  network are blocked.
- The drawer remains a named modal dialog with Escape, focus trap, focus
  return, swipe close, safe-area padding, 100dvh containment, and reduced
  motion support.

## Visual System

- Social Media deliberately preserves a Facebook-style blue/white command palette (`#1877F2`, white surfaces, cool-gray separators) across its full route family.
- The other thirteen families continue to use their own scoped world accent from the canonical registry.

The drawer now follows the Club Arena command-deck quality bar: black/navy
machinery surfaces, carbon striation, gunmetal framing, compact Rajdhani
labels, restrained per-world LED accents, three-pixel corners, and physical
selector plates. The header and fallback trigger use a six-node chrome command
grid. Horizontal menu bars are absent from source-owned World Hub UI and image
assets.

## Preserved Contracts

No Supabase table, RPC, RLS policy, realtime channel, API, form, mutation,
checkout, wallet, export, notification, route alias, or page-owned action was
removed or rewritten. The command layer is descriptive; existing server and
route authorization remain authoritative. Club Arena hard navigation remains
full-document navigation.

## High-Risk Exclusions

- No schema, RLS, wallet, settlement, checkout, or data migration changes.
- No compatibility-route deletion.
- No direct edit of compiled Club Arena output under `public/hub/club-arena`.
- No fabricated role visibility. Existing server/page guards continue to own
  access decisions; the shared capability vocabulary is available for later
  server-backed refinement.

## Permanent Gates

- Exactly 14 canonical worlds and six primary destinations per world.
- Shared footer/menu identity and Title Case at source.
- Dedicated configuration for every requested family.
- Global command coverage for all 203 physical owned routes.
- No source-owned World Hub image asset with hamburger/menu-bar naming.
- Exact approved command-grid header hashes.
- No duplicate approved-header and fallback triggers.
- Dialog, Escape, target-size, safe-area, z-index, overflow, and reduced-motion
  contracts.
- Existing menu and footer route-reachability laws remain mandatory.
