# MLB Analytics Frontend Deep Scan Audit
**Date:** June 25, 2026

## Objective
A rigorous line-by-line code audit of `pages/hub/MLB-ANALYTICS/**/*.tsx` and `components/mlb/**/*.tsx` focusing on data integrity in UI layers, unmasking arbitrarily clipped percentages, verifying conditional fallbacks, and checking for missing prop wirings.

## Findings & Resolutions

### 1. Edge Percentages / Win Probabilities Arbitrary Clipping
**Issue:** `Math.round()` and `.toFixed(0)` were aggressively truncating critical probability data, effectively hiding minor edge variances from the user.
**Files Impacted:**
- `pages/hub/MLB-ANALYTICS/props.tsx`
- `pages/hub/MLB-ANALYTICS/game/[id].tsx`
- `pages/hub/MLB-ANALYTICS/best-bets.tsx`
**Resolution:**
- Replaced `Math.round(Number(prop.win_confidence))` with `Number(prop.win_confidence).toFixed(1)` across `props.tsx`.
- Updated `slateStats.topLock` to display one decimal place `toFixed(1)` instead of integer rounding.
- Fixed the `formatPct` helper utility to output `.toFixed(1)` instead of `.toFixed(0)`.
- Updated conditional display of `bet.bet_score` in `game/[id].tsx` to respect one decimal place.

### 2. Fabricated Pitcher "Season K/GS" Fallback
**Issue:** Found a hardcoded math calculation in `best-bets.tsx` dividing `pitcher_so` by `Math.max(wins + losses, 1)`. This created a completely fake baseball stat (Strikeouts per Decision) masquerading as "Season K/GS", misleading users who expect real per-game strikeout rates.
**Files Impacted:** `pages/hub/MLB-ANALYTICS/best-bets.tsx`
**Resolution:** 
- Ripped out the false calculation.
- Repointed the UI binding to use the accurate `bet.pitcher_k_per_g` prop passed from the database. 
- Updated the label to "Season K/G".

### 3. Masked CSS Analysis
**Issue:** Checked for `display: none` and `opacity: 0` that might hide important backend data.
**Findings:** All instances were valid UI interactions (scroll-bar hiding for `scrollbar-hide` mixins, Framer Motion initialization states). No real data is being intentionally masked from view. 

### 4. Forgotten TODOs & Missing Prop Wirings
**Issue:** Unrendered variables or lingering stubs.
**Findings:** `RecentBetsTable.tsx` correctly propagates all edge parameters and pagination constraints. `MarketGradesPanel` fully utilizes its passed game contexts. No remaining `TODO` comments or unhandled default states like `|| 'No Data'` were found clipping the data feeds. 

**Result:** The frontend surface of MLB Analytics now perfectly reflects the decimal precision and statistical accuracy generated by the underlying model pipelines.
