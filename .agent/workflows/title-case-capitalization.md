# Title Case Capitalization Standard

## Rule

**ALL user-facing text** across the entire Smarter.Poker platform MUST use **Title Case** — capitalize the first letter of every word.

This applies to:
- Button labels (e.g., "Got It", "Don't Show Again", "Replay Tutorial")
- Modal/popup titles and descriptions
- Tutorial step titles and descriptions
- Menu items in hamburger menus
- Tab labels
- Toast/alert messages
- Page headings and subheadings
- Card titles and descriptions
- Error messages shown to users
- Placeholder text in inputs
- Tooltip text

## Examples

### Correct
- "Search By City Name, Venue Name, Or Zip Code To Find Poker Rooms"
- "Tap To Enable GPS — Venues Will Automatically Sort By Distance"
- "Don't Show Again"
- "Step 1 Of 12"

### Incorrect
- "Search by city name, venue name, or zip code to find poker rooms"
- "Tap to enable GPS — venues will automatically sort by distance"
- "Don't show again"
- "Step 1 of 12"

## Exceptions

- Code-facing strings (API keys, variable names, log messages) — NOT user-facing
- Brand names that have specific casing (e.g., "PokerAtlas", "iPhone")
- Acronyms remain all-caps (e.g., "GPS", "WSOP", "WPT")

## Enforcement

Before submitting any code that contains user-facing strings, verify every word starts with a capital letter. This is a zero-tolerance standard — the user should never have to request this correction.
