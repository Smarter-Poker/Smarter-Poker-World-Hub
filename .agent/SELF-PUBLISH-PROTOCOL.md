# Current self-submission and publication protocol

Read [the current delivery guide](../AGENTS-PUSH-GUIDE.md). It is the single
repository description of the working submission path and publication boundary.
The shared owner policy takes precedence over older instructions.

Use your owned worktree, ordinary authenticated Git/gh, required checks and
protected auto-merge. Never delete shared lock files, push directly to main,
copy or install dependencies into a worktree, or claim merge means live.
World Hub publication currently uses the separate approved local prebuilt
publisher; automatic World Hub publication is not installed.
