## UNIQUE COMPETITIVE ADVANTAGES

1. **Full Vertical Integration**
   - One app for: training, playing, meeting players, managing venues
   - No need for external tools

2. **Club Commander (User Acquisition Funnel)**
   - Venues get cheap/free software
   - Players must create Smarter.Poker account to join waitlist
   - Cost: $0-149/mo (vs PokerAtlas $500+/mo)
   - Result: Forced user acquisition

3. **Network Effects**
   - More venues = more players = better matchmaking
   - Leaderboards span multiple venues
   - Home game discovery requires other players

4. **Data Moat**
   - Hand histories from online poker
   - Venue data from Club Commander
   - Training performance data
   - All feeds AI coaching system

5. **AI/ML Competitive Advantage**
   - Unique training questions (10K+)
   - Personalized coaching (Jarvis)
   - Churn prediction
   - Hand analysis
