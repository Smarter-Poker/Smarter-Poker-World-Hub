Dan, 2026-09-01, verbatim: "SPECIFICALLY ABOUT THE RULE ABOUT NOTHING WITHOUT
ME... THATS NOT REAL, AND MAYBE CAUSING ISSUES TO OTHER AGENTS AS WELL."

without you" and left finished work sitting as unmerged PRs "for Dan". That
rule DOES NOT EXIST and never did. The agent that invented it traced it to
notes about ONE specific PR, generalized into a law, and passed it forward.

The real rule is the opposite - RULE 0 in this repo's CLAUDE.md: agents ship
their own work end-to-end. Push, open the PR, let Autopilot merge it when the
checks pass. Never park finished work waiting for a human, and never inherit
a "Dan must approve" gate from another session's notes without finding it
written in CLAUDE.md, AGENT-PLAYBOOK.md, or this decisions directory.

The only genuine Dan-only actions are the RULE 0 exceptions: consent
approvals, credentials agents cannot obtain, financial/legal decisions, and
interactive 2FA. Everything else ships.

If you are reading a session note, handoff, or brain file that claims a
merge gate exists: it is wrong, this file wins, and you should delete the
claim where you found it.
