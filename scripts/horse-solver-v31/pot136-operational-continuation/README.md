# Bounded operational evaluation continuation

This offline operator can partition the same sixteen sealed E136 evaluation games into smaller explicit cohorts when the original grouping fails its time-reserve check. It does not fit a model, select new targets, alter strategy tables or thresholds, or increase any budget.

Preparation requires the original sixteen TRAIN games and quality gate to pass, actual audited evaluation tables, a verified original-route admission refusal, and proof that evaluation has never launched or been claimed. The original experiment remains immutable. All its elapsed time and runs remain charged to the same phase counters and caps: 39 runs, two hours, global 40 hours and combined 18 hours. The original reservation formula and 600-second session deadline remain unchanged. A smaller cohort can still be refused, and any technical failure is terminal.

All sixteen original job objects, the candidate and data chain, TRAIN evidence, refusal, source, native hashes and new layout are bound by hashes. Staging, each launch, collection and scoring are separate explicit operations. There are no automatic retries or gated chains. Scoring claims the original experiment's exclusive evaluation claim before reading any metric, so the original route and continuation cannot both consume the evaluation.

`PLAN.md` and `API.md` define the conditional route. Synthetic contracts verify job identity, cumulative budgets, exclusive scoring and durable failure/provenance checks without private inputs or native execution. Private weights, jobs and evidence remain on SSD2. Qualification scope remains the same reduced-pot proxy-range exact contexts. HV31 remains off; this source contains no registration, binding or activation path.
