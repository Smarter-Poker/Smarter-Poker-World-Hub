# HV31 offline context-repair source

This directory contains the reviewed context-repair Python source as ordinary version-controlled files. It is not a trained or qualified model. HV31 remains OFF. No web route, gateway registration, scheduled job or engine entry point invokes these programs.

The code implements exact HJ/UTG game-domain dispatch, canonical TRAIN input/output binding, source and job provenance checks, mean-one fit weighting, cumulative budget and memory guards, and one-shot DEV/FINAL admission. The source-manifest records each unchanged reviewed file and the pre-label freeze identity. PLAN.md is the historical frozen research protocol; it does not authorize execution.

The original pipeline uses a private SSD2 workspace and maintained legacy research inputs. These inputs, root ranges, raw solver data, trained weights and heldout draw identities are deliberately absent from the repository. Do not invoke the collection, fitting or evaluation CLIs from this checkout. Any future execution needs a separately authorized, frozen workspace. Publishing this source neither resumes that work nor relaxes its safeguards.

Collection stopped at 73 of 94 TRAIN states; 21 were canceled. No actual candidate was fitted. DEV26 and NEW_FINAL32 remain unmeasured. R8 is rejected, B2 remains FAIL, and the globally unseen-flop certificate remains BLOCKED_ZERO. Earlier software-only checks passed; they do not establish poker strength.

The maintained V31 test suite executes test_source_contract.py against the actual source without importing private workspace modules, contacting M1, reading solver data, fitting a model or evaluating poker strength. The historical src/test_repair.py is retained byte-for-byte with the reviewed source and requires the private frozen workspace; it is not automatically invoked by repository CI.

Run the hermetic software contracts with the repository-pinned numerical interpreter:
