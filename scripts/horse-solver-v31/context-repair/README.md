# HV31 offline context and tail repair source

This is ordinary version-controlled research source, not a qualified model. HV31 stays OFF. No web route, gateway, scheduled job or engine entry point invokes these programs. Publication does not authorize collection, fitting, evaluation or live activation from this checkout.

The new frozen tail-repair protocol addresses two demonstrated weaknesses: a two-tone regression and failure of the per-state 3% storage-adjusted MES limit. TRAIN-only diagnostics found substantial conditional action regret already present in some teacher policies, especially responses to a small c-bet; this is a hypothesis about a contributing cause, not proof of a unique cause. The new target projection corrects high-regret TRAIN rows at the original solve tolerance. Two fixed architecture recipes, including dedicated two-tone heads, are selected by rank-grouped TRAIN CV using worst-family error before overall error. Inference never reads solver EVs or teacher labels.

The new protocol reuses 88 preserved, verified TRAIN jobs after excluding all new evaluation ranks. It prospectively reserves 32 never-solved exact class/context states, eight per family. Historical public TRAIN, sibling-rank and padding exposure are disclosed. Both the rejected context model and original D200R model are fixed comparators. Qualification requires improvement against both, no mean two-tone regression, and EVERY measured candidate state-seat upper bound at or below 3% root pot. Neither average improvement nor software test success is a strength certificate. The original globally unseen-flop certificate remains BLOCKED_ZERO; R8 remains rejected and B2 remains FAIL. Authored 80bb proxy ranges are not represented as qualified 200bb preflop ranges.

PLAN.md and source-manifest.json bind the exact new pre-fit protocol/source snapshot. The private SSD2 plan, selected identities, source harvests, feature arrays, model weights, raw solver outputs and consumed evaluations are absent. A candidate must be sealed before encoding or obtaining the one-shot evaluation labels, with separately reviewed actual job/padding/source hashes before any solver release. Old consumed evaluations and the prior unused NEW_FINAL32 remain excluded. Protected ledger sources are skipped without opening their contents. A pre-freeze hash-only excluded-input boundary mistake was recorded in private evidence, corrected before fitting, and is covered by a source regression; it is not described as compliant access.

The preserved legacy src/features.py and src/test_repair.py describe the earlier collection phase and are not invoked by this new preserved-TRAIN fit. Git history retains the earlier frozen protocol. Do not invoke research CLIs from this public package: their private inputs and release receipts are deliberately unavailable here.

The maintained V31 software suite invokes test_source_contract.py against the actual source. Fourteen hermetic contracts check target correction, the real serialized dispatcher, board normalization reaching the fitter, worst-family selection, canonical game identity, protected-source skipping, TRAIN-only padding, cumulative budgets, exact 3% boundaries, both-baseline and two-tone scorer enforcement, and one-shot consumption ordering. Synthetic scorer fixtures are software tests only. They do not collect labels, fit a real model, contact M1 or prove poker strength.
