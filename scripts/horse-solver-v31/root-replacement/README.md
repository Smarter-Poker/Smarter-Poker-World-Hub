# ROOT frequency replacement research

This offline pipeline completes missing full-ROOT public feature encodings, fits two fixed frequency replacements with global-rank folds, and screens their whole-seat flop policies against an incumbent on TRAIN contexts. It never activates HV31 or admits a final evaluation.

Read `PLAN.md` before use. Private inputs, teacher arrays, model weights, game identities and native results stay outside Git. `operator/prepare_inputs.py` documents the explicit role-bound preparation route; it refuses an existing freeze. Freeze the exact plan, source and allowed inputs before encoding or fitting. The source manifest records the implementation shipped here, not a qualification certificate.

The sequence is `encode_roots.py`, `fit_roots.py`, `build_train_jobs.py`, then explicit serialized native cohort operations through `ops.py`. Native execution requires an accepted release binding actual jobs, helpers, model provenance and successful A8 preflight. Read durable outcomes and collect each cohort through the canonical hash and A2 technical gate before admitting the next. Do not use the legacy launcher's wait mode to queue gated operations.

`score_train.py` claims the screen once, measures the opposite seat's in-tree MES gain above equilibrium plus the storage bound, and applies every frozen criterion. These values are percentages of root pot; they are not absolute two-player exploitability under rake. A failed screen permits no refit. A passing screen permits one selected all-TRAIN refit, still explicitly unqualified for final evaluation and live play. Coupled IP inference uses paired public cbet ROOT features and has no production serving adapter.

The physical tree is 200bb with authored 80bb proxy ranges and no jackpot drop. Historical incumbent exposure to TRAIN ranks makes this a conservative incumbent comparison, not equal-training generalization or unseen-flop qualification.

Run the maintained `npm run test:horse-solver-v31` route with its configured numerical Python. The eight synthetic contracts exercise action mapping, conditional realization, small probabilities, input refusal, budget accounting and the actual screen's claim/seat/unit logic without opening private research data or contacting a solver. Synthetic failing scores printed by these tests are fixtures, not experimental results.
