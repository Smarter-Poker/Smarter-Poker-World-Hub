# Player control qualification

Run `node scripts/qualify-player-control-pg17.mjs` on a disposable native PostgreSQL17 cluster. Set `PLAYER_CONTROL_POSTGRES_BIN` to the installed binary directory and `TMPDIR` to task-owned scratch (external SSD on macOS). The runner creates its own localhost cluster, loads the full unchanged migration, performs transaction assertions and independent-session concurrency proofs, then closes and removes only its owned cluster. No production connection or credentials are accepted.

The prerequisite hook and restrict/lift writers were read from configured production metadata on October10,2026. The hook fixture retains its exact emitted source; migration source/config preflight must pass without a hash waiver. Fixtures model external operator identity and the audit receiver, not the entire operator/approval product. Actual restriction decisions, row triggers, idempotency ledger, auth.sessions/refresh-token cascade, original hook patch, session-live reader and permissions execute as PostgreSQL SQL. Source gate continues to require whole-product authorization and approval regression tests.

Assertions cover policy-off observation with sessions preserved; admission, rebuy, add-on and re-entry refusal; withdrawal allowed; original money debit rolled back when each owned journal refuses; credits/removals allowed; horse restrictions; target-only logout; refresh token cascade; new login accepted; duplicate/replayed logout preserves new login; old Data API token refused; new token accepted; restriction replay after lift cannot reapply; changed intent rejected; privileged RPC ACLs. Native mode additionally verifies admission waits on the original restriction decision then sees its committed result, and duplicate logout from separate sessions audits once.

A provisional local fallback uses `--pglite` and `PLAYER_CONTROL_PGLITE_MODULE=/absolute/owned/path/to/pglite/dist/index.js`. This executes unchanged migration in PostgreSQL WASM and covers sequential transaction assertions. It does not replace the native independent-session gate. Native qualification must pass before merge/install.
