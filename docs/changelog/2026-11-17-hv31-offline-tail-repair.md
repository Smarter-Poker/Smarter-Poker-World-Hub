# HV31 offline tail-repair protocol

The offline context-repair source now implements a new frozen protocol for correcting high conditional-regret TRAIN targets and comparing pooled models with dedicated two-tone heads. Grouped TRAIN selection prioritizes the worst family. The encoder uses only the frozen TRAIN padding allowlist, and exact-game freshness checks canonicalize suit/order aliases while skipping protected job contents. The F5TAIL phase remains charged to existing cumulative solver budgets.

The one-shot finite-context assessment compares both previous baselines, requires no mean two-tone regression, and retains the 3% storage-adjusted upper limit for every measured state and seat. Fourteen hermetic source contracts exercise the new behavior through the existing V31 suite. Private data, selected evaluation identities and trained weights are excluded from this publication. This is research source, not model qualification or a live serving change; HV31 remains OFF.
