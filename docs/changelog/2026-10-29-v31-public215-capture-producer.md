# V31 public215 capture producer

This change preserves the existing six-file pipeline and adds an explicit
nine-file public215 contract. Approved input identity includes public templates,
training and partition protocols, dependency and physics identities, and the
public feature schema. Model and immutable post-training execution receipts use
the existing authenticated COMPACTOR boundary, with distinct private prepare and
freeze operations; preparation cannot seal, promote or expose runtime cells.

The final M1 trainer requires the complete approved capture census and authentic
normalized database checksums before fitting. It preserves source order, original
weights, frozen hyperparameters and the globally selected direct variant.
Numeric tree export is lossless; executable serialized models are not accepted.

The M2 worker checks complete server-side frozen-model authority before opening
the seed file. Its approved candidate superset is narrowed by the frozen HMAC
selection without changing the approved manifest. The seed is a transient
request-only opening, excluded from stored artifacts, logs and receipts. These
source changes do not themselves certify a dataset or prove live availability.
