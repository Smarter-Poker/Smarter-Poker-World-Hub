# V31 authored conditional response histories

A finite input study can have legal positive root ranges but no equilibrium
occurrence mass at an authored later decision. Adding more boards cannot repair
that historical reach loss. The producer now supports an explicit singleton
`conditional_history` model that fixes the preceding actions while retaining the
target's choices. It derives Pio's cumulative numeric prefix from the existing
node chronology and keeps chance cards out of `force_line`.

This is a new exogenously conditioned, range-preserving response study. It is not
an unconstrained equilibrium or natural-occurrence certificate. The complete
approved manifest and new immutable pipeline identity disclose the intervention;
old root-jam models and ordinary studies retain their behavior. New input
approval and fresh independent exports are mandatory.

Every conditioned export refuses changed legal support or relative weights for
either player's input range, and refuses missing actual matchup mass for any
legal positive actor input with a compatible positive opponent. No probability
floor or invented reach is allowed. Exact target children, action mapping,
canonical context, public pot, utility model and all qualification gates remain.

The existing enforced Python suite covers cumulative multi-street prefixes,
invalid/ambiguous bindings, unchanged root-jam behavior and runtime support
refusal. The optional explicit `native_conditional_preflight.py` driver additionally
requires pinned licensed executable, hand order and candidate source identities;
it contacts no gateway and writes no source artifact. A native pass remains
separate from full fresh-harvest, independent-holdout and live-consumer proof.
