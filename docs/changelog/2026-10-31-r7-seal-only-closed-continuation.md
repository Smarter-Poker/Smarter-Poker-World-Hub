# R7 resumes only its rolled-back seal

The original R7 continuation completed its 107 inherited builds and all 856 heldout audits, then its seal request timed out. The original database transaction subsequently reported SQLSTATE 57014 and rolled back; repeating the compactor would repeat already completed work.

The seal-only controller pins the original claims, failure records, all 854 new acknowledgements and the two preserved outcomes. It requires fresh independent 107-cell/856-audit evidence, the exact terminated transaction identity and a qualified installed migration bound to all five affected function definitions. It makes one seal request and one status read. Unknown outcomes stop for durable readback; no build, audit, seed access, evaluation or promotion is invoked.

Eight focused safety cases execute through the existing required pipeline wrapper. Protected integration, installation, an actual successful seal and downstream qualification/loading/live proof remain separate acceptance gates.
